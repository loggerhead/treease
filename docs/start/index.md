# Start

`start/` 承接 Treease 的产品入口。这里先解释它解决什么问题、服务哪些用户、核心体验链路是什么，再把读者导向具体技术主题。

Treease 面向的是“结构化文本既要编辑、又要理解、还要转换”的连续工作流。它不是单纯的 formatter，也不是单纯的 graph viewer，而是把文本、结构、路径和导出收敛到同一份文档 authority 上。
